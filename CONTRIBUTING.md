# Contributing to Earnexx

Thank you for your interest in contributing to Earnexx.

Earnexx is an early-stage Solana-native project, and contributions are welcome as the project evolves.

---

## Ways to Contribute

You can help by:
- Reporting bugs or issues
- Suggesting features or improvements
- Reviewing documentation
- Testing early releases (when available)
- Submitting pull requests
