# Earnexx – On-Chain Rewards Platform

Earnexx is a Web3 platform on Solana that helps users earn rewards by completing tasks and engaging with the community. It provides instant, transparent, on-chain incentives to drive growth, adoption, and engagement across the Solana ecosystem.

## 🚀 Features

**Task & Community Rewards**  
Users can complete tasks, engage with projects, and earn on-chain rewards automatically tracked on Solana.  

**Transparent & On-Chain**  
All reward distribution and user activity are recorded on-chain, ensuring transparency and verifiability.  

**Real-Time Progress Tracking**  
Users can see earned rewards, completed tasks, and leaderboard positions in real-time.  

**Scalable & Multi-Project Ready**  
Earnexx can integrate with multiple Solana projects, supporting reward campaigns and growth incentives across the ecosystem.

## ⚙️ How It Works

1. Users connect their Solana wallet.  
2. Complete tasks assigned by projects (social engagement, campaigns, testing, etc.).  
3. Earn rewards automatically, tracked on-chain.  
4. Admins can monitor participation, distribute incentives, and verify task completion.
