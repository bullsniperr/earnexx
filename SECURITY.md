# Security Policy

## Reporting a Vulnerability

Earnexx takes security seriously. If you discover a security vulnerability or potential exploit, please report it responsibly.

### How to Report

Report security issues privately by contacting:

- **Email:** bullsniperr@gmail.com  
- **X/Twitter DM:** @Bullsniperr  

Include as much information as possible:
- Description of the issue
- Steps to reproduce
- Potential impact
- Screenshots, logs, or code references

### What to Expect

- Acknowledge receipt as soon as possible  
- Investigate and assess the issue  
- Provide updates and work on a fix before public disclosure  

**Do not** publicly disclose vulnerabilities before they are addressed.

---

## Scope

This policy applies to:

- Smart contracts (once deployed)  
- Off-chain services  
- Documentation or tooling in this repository  

## Response Timeframe

- Initial acknowledgement: within 48 hours  
- Assessment and fix timeline: depends on severity; high-risk issues prioritized
