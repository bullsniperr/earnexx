# Security Policy

## Reporting a Vulnerability

Earnexx takes security seriously.  
If you discover a security vulnerability or potential exploit, we encourage responsible disclosure.

### How to Report

Please report security issues privately by contacting:

- **Email:** earnexx01@gmail.com 
  (temporary contact – will be updated as the project evolves)

If email is unavailable, you may also reach out via:
- Direct message to the project lead on X (twitter) https://x.com/earnexx

### What to Include

When reporting a vulnerability, please include:
- A clear description of the issue
- Steps to reproduce (if applicable)
- Potential impact
- Any relevant screenshots, logs, or code references

### What to Expect

- We will acknowledge receipt of your report as soon as possible
- We will investigate and assess the issue
- We will work on a fix before any public disclosure

Please **do not** publicly disclose security issues until they have been reviewed and addressed.

---

## Scope

This policy applies to:
- Smart contracts (once deployed)
- Off-chain services
- Documentation or tooling hosted in this repository

Thank you for helping keep Earnexx and its users safe.
